# Ear Training Lab

A browser ear trainer for practising with my harmony teacher:

- the first five notes of major, minor, Phrygian and Lydian
- intervals up to the sixth
- chord inversions
- tensions

Works on desktop (keyboard shortcuts) and on phone (bottom Play/Next bar, tappable piano, swipe left for next).
Open `index.html` or the GitHub Pages site. On iPhone, turn off silent mode to hear sound.
